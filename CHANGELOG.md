# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-07-28

- Added semantic GNU PO/POT parsing and deterministic serialization.
- Added GNU MO revision 0 reading and writing for both byte orders.
- Added a checked `Plural-Forms` lexer, parser, and evaluator.
- Added runtime singular, contextual, plural, and fallback lookup.
- Added validation reports, catalog statistics, flags, and source references.
- Added exact-key POT/PO merging with obsolete-entry handling.
- Added native validation/compile/normalize/inspect CLI and pure example.
- Added cross-target tests and CI acceptance gates.
