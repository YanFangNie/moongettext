# moongettext

`moongettext` is a pure MoonBit toolkit for GNU gettext catalogs. It provides
PO/POT parsing and writing, plural-form evaluation, MO binary compilation and
loading, validation, and runtime translation lookup.

The implementation is original MoonBit code informed by the public GNU gettext
file-format documentation. No source code from GNU gettext is copied.

> The public API and compatibility table will be expanded alongside the
> implementation. The repository is currently under active development.
